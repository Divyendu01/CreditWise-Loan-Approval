
# CreditWise Loan Approval

A supervised machine learning project that predicts whether a loan application should be approved based on applicants’ demographic, financial, employment, credit, and loan-related information.

## Approach

- Data preprocessing & missing-value handling
- Exploratory data analysis
- Categorical encoding & feature scaling
- Feature engineering
- Logistic Regression, K-Nearest Neighbors (KNN) & Naive Bayes
- Model evaluation using accuracy, precision, recall & F1-score

## Dataset

Applicant demographic, financial, employment, credit, and loan application data.

## Results

Achieved **88% accuracy using Logistic Regression** after feature engineering and compared model performance across Logistic Regression, KNN, and Naive Bayes.

## Tech Stack

Python · Pandas · NumPy · Matplotlib · Seaborn · Scikit-learn · Jupyter Notebook
